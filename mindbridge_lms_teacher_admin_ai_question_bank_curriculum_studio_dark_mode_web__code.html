(a) Standard Integral Transformation:

Let $f(x)$ be a continuous function defined on $[0, a]$. By considering the substitution $u = a - x$, prove that:

∫0a f(x) dx = ∫0a f(a - x) dx
[10 Marks]

(b) Integration & Definite Limit Evaluation:

Hence, or otherwise, determine the exact numerical value of the definite integral:

I = ∫0π
x · sin(x) 1 + cos2(x)
dx
Target Verification: Show rigorously that I = π2 / 4
[15 Marks]
