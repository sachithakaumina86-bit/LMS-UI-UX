Question 3: Prove \(\cos(5\theta) = 16\cos^5(\theta) - 20\cos^3(\theta) + 5\cos(\theta)\)

[25 Marks]

Let \( z = \cos\theta + i\sin\theta \). By De Moivre's Theorem:
\( z^5 = (\cos\theta + i\sin\theta)^5 = \cos(5\theta) + i\sin(5\theta) \)

Binomial expansion:
\( z^5 = \cos^5\theta + 5i\cos^4\theta\sin\theta - 10\cos^3\theta\sin^2\theta - 10i\cos^2\theta\sin^3\theta + 5\cos\theta\sin^4\theta + i\sin^5\theta \)
check_circle Rigorous Step (+15)

Equating Real parts:
\( \cos(5\theta) = \cos^5\theta - 10\cos^3\theta(1-\cos^2\theta) + 5\cos\theta(1-\cos^2\theta)^2 \)
\( = \cos^5\theta - 10\cos^3\theta + 10\cos^5\theta + 5\cos\theta(1 - 2\cos^2\theta + \cos^4\theta) \)

\( = 16\cos^5\theta - 20\cos^3\theta + 5\cos\theta \)   [Q.E.D.]

info State domain: \(\theta \in \mathbb{R}\)
