## Brand & Style

This design system powers a specialized, mission-critical Learning Management System built for Sri Lankan G.C.E. Advanced Level academies, master tutors, and rigorous Combined Mathematics students. The brand ethos embodies academic authority, razor-sharp mathematical precision, and motivating focus. 

The aesthetic is **Deep Oceanic High-Contrast Tech**: an immersive, distraction-free obsidian atmosphere punctuated by electric cobalt energy and amber-gold milestones. The interface delivers cognitive calm during marathon problem-solving sessions while instilling prestige and institutional trust for tuition masters managing thousands of active admissions, bank slip verifications, and real-time timed mock exams.

### Design Principles
- **Cognitive Serenity:** The deep midnight palette eliminates night-time glare and visual fatigue, creating an uninterrupted flow state for high-stakes calculus, mechanics, and pure mathematics problem sets.
- **Mathematical Exactness:** Layouts honor KaTeX mathematical rendering, analytical coordinate charts, paper mark breakdowns, and bilingual typographic metrics without clipping or layout shifts.
- **Operational Clarity:** High-contrast accent signifiers immediately distinguish between administrative verification flows (slip authenticated, pending review, anti-cheat flag triggered) with zero visual ambiguity.

## Colors

The color architecture is built natively for dark mode environments, operating on calibrated midnight tonal steps that satisfy WCAG AAA legibility across OLED and standard IPS panels.

### Surface System
- **Background Root:** `#0B1120` (Deep midnight oceanic obsidian base canvas)
- **Surface Dim:** `#080D1A` (Underlying structural wells, backdrop recessions)
- **Surface Default:** `#0F172A` (Default canvas layer for primary views)
- **Surface Bright:** `#1E293B` (Elevated interactive controls, toolbars, popovers)

### Surface Containers (Tonal Layering)
- **Container Lowest (`#070B14`):** Recessed equation editors, code blocks, dark diagram canvases.
- **Container Low (`#0D1527`):** Large structural sidebars, secondary content panels, persistent drawers.
- **Container Default (`#131E36`):** Standard modular card surfaces, lesson modules, batch matrices.
- **Container High (`#1A2846`):** Active table rows, floating dialog headers, highlighted problem tiers.
- **Container Highest (`#23355A`):** Hover states, contextual popups, quick-action chips.

### Accent & Semantic Tokens
- **Primary (Electric Cobalt `#3898FF`, Deep `#2563EB`):** Interactive focal points, video playback scrubber, active exam step progress, primary CTAs.
- **Secondary (Amber Gold `#F59E0B`, Vibrant `#EAB308`):** Academic achievements, island-rank percentiles, master tutor badges, premium cohort tags.
- **Success (Emerald Green `#10B981`):** Verified bank transfer slips, passed proofs, full marks, zero penalty flags.
- **Critical (Crimson Red `#EF4444`):** Anti-cheat violations (tab-switch triggers, multi-session flags), overdue cohort tuition, locked exam timeouts.
- **Subtle Glowing Borders:** Baseline `#1E293B`, interactive hover `#334155`, active primary halo `rgba(56, 152, 255, 0.2)`.

### Text & Readability Contrast
- **Text Primary (`#F8FAFC`):** Strict 14.5:1+ contrast against all surface tiers for lesson theorems, numerical indices, and mathematical script.
- **Text Secondary (`#94A3B8`):** Sub-headings, metadata markers, exam timing criteria.
- **Text Muted (`#64748B`):** Inactive steps, placeholder notes, table column timestamps.

## Typography

The type system is powered by **Plus Jakarta Sans**, chosen for its tall x-height, open geometric apertures, and crystal-clear rendering on dense student dashboards. 

### Bilingual & Script Standards
- **English & Latin Scripts:** Rendered via Plus Jakarta Sans with tabular figures enabled (`font-feature-settings: "tnum" 1`) for index ranks, marks lists, and exam countdowns.
- **Sinhala Unicode Integration:** Integrated with high-legibility system fallbacks (`Noto Sans Sinhala`, `Iskoola Pota`) ensuring complex conjunct characters (බැඳි අකුරු) and vowel signs (පිල්ලම්) preserve baseline alignment without vertical truncation or awkward line collisions.
- **KaTeX Formula Support:** Mathematical notation (integration signs, matrices, complex vectors) renders in hardware-accelerated KaTeX font sets. Line-heights for containers containing inline KaTeX formulas must automatically expand by `1.25x` to avoid clipping superscripts and radical symbols.

## Layout & Spacing

The layout is engineered around an **8-point mathematical spacing system** utilizing a 12-column fluid grid on desktop and reflowing into compact stacked structures on mobile viewport sizes.

### Grid Metrics
- **Desktop (>= 1280px):** 12-column fluid grid, `2rem` outer margins, `1.5rem` gutters. Left-anchored persistent navigation sidebar (`260px` or `72px` collapsed state).
- **Tablet (768px - 1279px):** 8-column layout, `1.5rem` margins, `1rem` gutters. Drawer-based navigation navigation sheet.
- **Mobile (< 768px):** 4-column layout, `1rem` margins, `0.75rem` gutters. Sticky bottom exam action dock for one-handed operation during mobile practice tests.

### Layout Rules for LMS Modules
- Exam and lesson problem containers have a strict maximum content reading width of `840px` to maintain optimal line-length for complex Combined Maths proof comprehension.
- Data-heavy student grade sheets, slip reconciliation screens, and multi-tenant batch management views expand to `100%` container width with horizontal freeze-panes for student IDs and verification statuses.

## Elevation & Depth

Visual hierarchy uses **tonal layer nesting** combined with faint, crisp inner borders and tinted, luminous atmospheric halos. Heavy drop-shadows are eliminated in favor of luminance cues that maintain absolute clarity in dark environments.

### Elevation Levels
- **Level 0 (Base Canvas - `#0B1120`):** The foundational substrate. Used for viewport backgrounds and uncontained page margins.
- **Level 1 (Subordinate Wells - `#070B14`):** Inset containers, KaTeX formula inputs, and raw code/scratchpad areas with a 1px solid border in `#1E293B`.
- **Level 2 (Default Cards & Shelves - `#131E36`):** Primary lesson cards, payment slip previews, and forum cards. Layered with a 1px border of `#1E293B` and an ambient glow of `0 8px 24px -4px rgba(7, 11, 20, 0.6)`.
- **Level 3 (Interactive Floating & Hover States - `#1A2846`):** Active question step, focused input fields, contextual action bars. Border shifts to `rgba(56, 152, 255, 0.4)` paired with an electric aura `0 0 16px rgba(56, 152, 255, 0.12)`.
- **Level 4 (Modals, Timed Exam Overlays, Verification Drawers - `#23355A`):** Critical modal interfaces resting over a `rgba(7, 11, 20, 0.85)` backdrop blur (`16px`). Edge highlighting via a subtle top-light border `1px solid rgba(248, 250, 252, 0.12)`.

## Shapes

The shape vocabulary uses structured, contemporary geometric curvature (**Level 2 - Rounded**). This creates an inviting, premium aesthetic while keeping mathematical visualizations and telemetry cards clean and legible.

### Border Radius Tokens
- **Interactive Inputs, Form Controls, Buttons, Badges (`rounded-md`):** `0.5rem` (8px). Delivers a crisp, tactile tap target.
- **Cards, Exam Step Containers, Content Panels (`rounded-lg`):** `1rem` (16px). Balances soft boundary framing with structured density.
- **Parent Modules, Floating Dialogs, Full Modal Panels (`rounded-xl`):** `1.5rem` (24px). Creates distinct modal zoning without aggressive bubble curves.
- **Status Pills, Progress Bullets, Verification Avatars (`rounded-full`):** `9999px`. Reserved for tags, avatar indicators, and interactive round timer rings.

## Components

### Buttons
- **Primary Action (Electric Cobalt):** Background `#3898FF`, text `#070B14` (Font Weight 700), `rounded-md` (8px). Hover state transitions to `#2563EB` with text `#F8FAFC` and an interactive drop aura `0 0 12px rgba(56, 152, 255, 0.35)`.
- **Secondary Action (Subtle Obsidian):** Background `#131E36`, border `1px solid #1E293B`, text `#F8FAFC`. Hover brings border to `#334155` and background to `#1A2846`.
- **Destructive / Anti-Cheat Trigger:** Background `rgba(239, 68, 68, 0.15)`, border `1px solid rgba(239, 68, 68, 0.4)`, text `#EF4444`. Hover fills solid `#EF4444` with `#FFFFFF` text.

### Verification Chips & Status Badges
- **Slip Verified / Active Admission:** Emerald Green pill (`rgba(16, 185, 129, 0.15)`), border `1px solid rgba(16, 185, 129, 0.35)`, text `#10B981`, label-sm, uppercase. Includes a 6px pulse dot.
- **Slip Under Review / Deferred:** Amber Gold pill (`rgba(245, 158, 11, 0.15)`), border `1px solid rgba(245, 158, 11, 0.35)`, text `#F59E0B`.
- **Overdue / Flagged Access:** Crimson Red pill (`rgba(239, 68, 68, 0.15)`), border `1px solid rgba(239, 68, 68, 0.35)`, text `#EF4444`.

### Input Fields & Search Bars
- Standard state: Background `#070B14`, border `1px solid #1E293B`, text `#F8FAFC`, placeholder `#64748B`, `rounded-md` (8px). Padding `0.625rem 1rem`.
- Active focus state: Border `1px solid #3898FF`, box-shadow `0 0 0 2px rgba(56, 152, 255, 0.25)`. KaTeX formula input preview renders synchronously underneath the input container in a dedicated `#0D1527` tray.

### Cards & Problem Panels
- Modular dark surface `#131E36` enclosed with `1px solid #1E293B` and `rounded-lg` (16px).
- Internal header areas use Container High `#1A2846` with split meta-information: question difficulty tier, marks allocation pill (e.g., "[25 Marks]"), and bilingual question label toggle (English / සිංහල).

### Checkboxes & Multiple Choice Selectors (A/L MCQ Format)
- Choice wrappers: Full-width container `#0D1527` with `1px solid #1E293B` and `rounded-md`.
- Selected answer state: Background `#131E36`, border `1.5px solid #3898FF`, box-shadow `0 0 8px rgba(56, 152, 255, 0.2)`. The index indicator (e.g., "(1)", "(2)", or "A", "B") changes from `#94A3B8` to `#3898FF` bold.

### Domain-Specific Components
- **Timed Exam Tracker Dock:** Sticky bottom drawer displaying remaining minutes/seconds with high-visibility tabular numbers, auto-save status indicator, and question jump grid.
- **Bank Slip Inspection Splitter:** Side-by-side inspection view featuring zoomable image pan on the left and student admission record with quick-action approval keys on the right.
- **KaTeX Scratchpad Canvas:** Embedded coordinate axis grid tool with clear, erase, and direct formula export to tutor feedback submissions.
